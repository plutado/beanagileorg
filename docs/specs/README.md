# Design specs

The plans the apps were built from, kept company-neutral. They were written before the code, so where they and the code differ, the code and the main README are current.

- [Toolkit](toolkit.md): data model, privacy levels, screens, API, tokens, sharing.
- [Comms studio](comms-studio.md): messages, templates, writing checks, decks, media, images and infographics, Ask.
- [Video message platform](video-message-platform.md): a gated share site for short video messages, comments and the dev-sync board. Not built yet.
- [Sharing between installs](sharing-between-installs.md): granular export, import and merge of chosen records and fields between managers' copies. Partly built: packs with eight kinds, preview and merge, signing, the roster file and the coaching pack.
- [Judgments about people](judgments-about-people.md): where personal judgment and personal information live, what never leaves, and the second look before wording that might be a judgment goes out. Built for packs and the roster file.
